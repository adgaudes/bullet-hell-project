# Project governance

Prima di modifiche sostanziali, leggi `AGENTS.md` e soltanto i documenti collegati alla parte del progetto su cui devi intervenire.

- Lavora solo sui file indicati nel task e non ampliare lo scope.
- Tratta concept e feature candidate come non approvati.
- Non modificare manualmente file Unreal binari `.uasset` o `.umap`.
- Non aggiungere dipendenze, plugin, asset o costi senza approvazione.
- Non accedere o riportare credenziali, token o dati riservati.
- Consegna un diff piccolo con riepilogo, assunzioni, test, risultati e rischi residui.
- Non dichiarare successo senza test riproducibili; segnala chiaramente cio che non hai verificato.
- Codex eseguira revisione, integrazione e verifica finale.

Usa il minimo contesto necessario e risposte concise. Il repository e la fonte condivisa di verita.
